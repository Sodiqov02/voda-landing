# voda-landing

Static responsive implementation based on the provided Figma layout for the “Боровая” water storefront.

## Files
- `index.html` — page markup
- `styles.css` — responsive styles
- `script.js` — small product quantity/cart interaction

## Notes
The first pass reproduces the Figma structure and typography closely. Some imagery is referenced from the public `vodaborovaya.by` site because the Figma Starter MCP quota was reached while downloading the remaining original assets. These can be localized later into `/assets` when the quota resets.
